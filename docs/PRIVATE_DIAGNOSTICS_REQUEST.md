# Private capture request template

Replace the greeting, issue number, question and command before sending. Check
the reporter's exact model, topology, region and compatible setup first. Use
this only when private evidence can answer a specific unresolved question.
For an existing capture, ask for that rather than another camera run.

```text
Hey {name},

A short private capture would help me work out {specific question}. It can contain footage, audio and device information, so only do this if you're comfortable sharing it. We can carry on with ordinary troubleshooting if you'd rather not.

Please could you follow https://github.com/mscodemonkey/eufy-mega-security/blob/main/docs/PRIVATE_DIAGNOSTICS.md and use the exact command I've supplied below for a 30-second attempt. The tool stops automatically and doesn't upload anything.

{exact supported command, including the agreed channel and sensor}

Then send the ZIP to mscm.projects@gmail.com with issue #{number} in the subject and a quick note saying what happened. If it's too big for an attachment, a private cloud link shared with that email address is fine. Please keep the file and link out of the public issue, and don't include passwords or session files.

Thanks for helping me investigate this one!

Cheers,
Mart
```
